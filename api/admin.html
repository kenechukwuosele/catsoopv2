Loading courses...

ℹ️ How the Queue Works
Students
Visit COURSE/queue to join the queue, describe their problem, and wait for help.
Instructors
See all waiting students, claim requests, and mark them as resolved from the same URL.
During Labs
Project the queue on screen so students can see their position and expected wait time.
After Hours
Queue history is logged so you can review common issues across sessions.
